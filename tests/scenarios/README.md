# Planned business scenarios

No scenario implementation or provider evaluation has been run. Build deterministic fixtures for:

- A message producing an allowed finding, supported suspicion, an established violation, or incomplete assessment.
- Quoted conduct and reports preserving the original author's identity.
- Exact authorized staff actions bypassing AI while using the same durable execution controls.
- An A → B → A source sequence without a reliable event ID preserving the final observation; historical content hashes never suppress it.
- Duplicate creates/reports yielding one original-message case, and stale model completions.
- Original content assessed after edits/deletion; newer message bodies never replace original evidence.
- An event-driven ban commits its exact original evidence, accepted reason/policy and action links
  before dispatch; failed commit sends nothing. Source deletion and routine Intake/Jobs cleanup
  leave those retained details and the recorded outcome reviewable. Required evidence expiry
  exposes its purge time/reason without reconstructing content.
- Missing original capture or content-intent coverage produces incomplete evidence rather than a fabricated original.
- Webhook/system provenance never invents a human sanction target.
- An authenticated staff unban using current authority and shared target execution controls without rewriting the original finding.
- A ban created by another moderator never being reversed through guessed attribution.
- Conversation silence leaving moderation active.
- Personal-memory consent and deletion changing during generation, embedding or reply delivery.
- Debate scoring using a frozen transcript and never changing access rights.
- A reply remaining deliverable after its accepted Jobs payload is purged.
- A canceled request whose previously dispatched reply later succeeds, preserving both facts.
- Temporary guild unavailability without uninstall cleanup or installation-generation changes.
- Interaction token expiry or a vanished reply target without an implicit public fallback.

Assert both the business state and the external-operation requests. Missing provider data cannot become evidence of misconduct. Record separate coverage and quality results when evaluating real models.
